# @hyphacommerce/app-bridge

The app's side of Hypha's admin bridge. Part of [Hypha](https://github.com/hyphacommerce/hypha), the open-source commerce
API in Rust. Hypha is in public beta: this package follows the API's version and may change
between 0.x releases.

For a page embedded in the Hypha admin: session tokens, navigation, toasts, resource
pickers and resizing, over `postMessage` with exact origins. No dependencies, no
framework. `@hyphacommerce/app-bridge/testing` fakes the host for tests.

See https://hyphacommerce.com/docs/apps.
