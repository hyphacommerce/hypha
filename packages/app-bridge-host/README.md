# @hyphacommerce/app-bridge-host

The admin's side of Hypha's app bridge. Part of [Hypha](https://github.com/hyphacommerce/hypha), the open-source commerce
API in Rust. Hypha is in public beta: this package follows the API's version and may change
between 0.x releases.

Answers an embedded app page's messages. Hypha's own admin uses it; a custom admin mounts
app pages the same way. No framework.

See https://hyphacommerce.com/docs/apps.
