# @hyphacommerce/storefront-elements

Loading apps' storefront elements into any storefront. Part of [Hypha](https://github.com/hyphacommerce/hypha), the open-source commerce
API in Rust. Hypha is in public beta: this package follows the API's version and may change
between 0.x releases.

`loadElement` and `mountElement` load an app's web component from its URL and type its
events; `@hyphacommerce/storefront-elements/react` wraps them as `<HyphaElement>` (React
is optional).

See https://hyphacommerce.com/docs/apps.
