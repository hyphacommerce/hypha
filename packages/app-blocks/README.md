# @hyphacommerce/app-blocks

Hypha's declarative app blocks, format v1. Part of [Hypha](https://github.com/hyphacommerce/hypha), the open-source commerce
API in Rust. Hypha is in public beta: this package follows the API's version and may change
between 0.x releases.

The JSON Schema (`@hyphacommerce/app-blocks/schema/block.v1.json`), TypeScript types, a
`validateBlock` function and, at `@hyphacommerce/app-blocks/react`, the reference
`<HyphaBlock>` renderer on Astryx (a peer dependency), for admins that show apps' blocks.

See https://hyphacommerce.com/docs/apps.
